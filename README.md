# US Cities Search

A web application that searches U.S. city information by ZIP code or city name using an Azure-hosted USCities Microservice and MongoDB Atlas.

## Features

- Search by ZIP code
- Search by city name
- Fetches data from an Azure-hosted REST API
- Displays results in a responsive table
- Input validation and error handling

## Technologies

- HTML
- CSS
- JavaScript
- Azure App Service
- MongoDB Atlas
